## 🎨 Design System: "Aether Arcade"

- **Design Movement**: Ethereal Retro-Futurism & Neo-Arcade
- **Color Palette**:
  - Primary Beam Blue: `#006194` / `#0284c7`
  - Stratosphere Cyan: `#38bdf8`
  - CRT Phosphor Halo: `#7dd3fc`
  - Vintage Computer Chassis: `#eadeca` / `#dfd0bc` / `#cfbfa9`
  - Vacuum Midnight Text: `#131b2e` / `#0f172a`
- **Typography**:
  - Headings / Display: **Space Grotesk**
  - Arcade & Monospace Data: **VT323**, **Press Start 2P**, **Space Mono**
