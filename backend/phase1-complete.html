📡 API Endpoints (Phase 1)

Base URL: http://localhost:3000/api

Judges

GET /judges

Returns all 5 AI judges with channel numbers and severity ratings.

Dresscodes

GET /dresscodes

Returns 7 dresscode themes for the Lucky Wheel with colors, rules, and violations.

Settings

GET /settings
PUT /settings

Get or update user settings (sound, display, privacy preferences).

Lucky Wheel

GET /wheel/week-plan
POST /wheel/spin
POST /wheel/auto-week

Manage 7-day dresscode assignments with cryptographically random spins.

🚀 Quick Start

1. Install Dependencies

cd backend
npm install

2. Configure Environment

cp .env.example .env
# Edit .env - set MOCK_AI=true for testing

3. Seed Database

npm run seed

4. Start Server

npm run dev

Server starts at http://localhost:3000

🧪 Test the API

# Health check
curl http://localhost:3000/health

# Get judges (creates guest session)
curl http://localhost:3000/api/judges -c cookies.txt

# Get dresscodes
curl http://localhost:3000/api/dresscodes -b cookies.txt

# Spin the wheel for Tuesday
curl http://localhost:3000/api/wheel/spin \
-X POST -H "Content-Type: application/json" \
-d '{"day_index":1}' -b cookies.txt
