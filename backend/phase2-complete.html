🔌 API Integration Points

GET /api/wheel/week-plan

Loads on page startup. Returns 7-day plan with dresscode assignments.

POST /api/wheel/spin

Called by all spin buttons. Payload: { day_index: 0-6 }. Returns segment index and dresscode.

POST /api/wheel/auto-week

Auto-generate button. Shuffles all 7 dresscodes and saves to user's plan.

GET /api/settings

Loads on page startup. Returns sound, CRT mode, and privacy settings.

PUT /api/settings

Called by audio and scanline toggles. Persists user preferences.
